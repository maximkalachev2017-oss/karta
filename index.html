Смещение подставляется автоматически по городу с учётом летнего и «декретного» времени на дату рождения. Ручное значение (например, 4 или 5.5) имеет приоритет.

Данные сохранены только в этом браузере.

Все расчёты выполняются на устройстве, данные никуда не отправляются. Только для кнопки PDF страница один раз загружает модули и шрифт из открытой библиотеки (cdn.jsdelivr.net), без ваших данных.
